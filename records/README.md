# Original function reconstruction records

`reviewed_functions.csv` is the manually reviewed, address-indexed source
ledger. `function_status.csv`, `work_queue.csv`, `dependency_groups.json`
and `summary.json` are generated by `tools/build_reconstruction_index.py`.
The original analysis evidence remains under `analysis/reconstruction/`;
its historical path strings refer to the repository layout at the time of
that evidence. The migration does not upgrade any reconstruction stage.

Regenerate with `python tools/build_reconstruction_index.py`, then
`python tools/build_remaining_architecture.py`.

# Maze corridor and physical input correction

Original 0041AF60/004211A0 produce +1 for raw input bit 4, which 0041B140/00421360 subtract from Y. The normalized host has bit 4=Up. Previously both drivers inverted this mapping. The shared source scan now occurs before direction admission, including idle frames; capture updates the corridor permission bits. The source constants at 43B448/43B458/43B4C0 are 30/6/20; the Spud-specific attraction and latch reset radii differ from Maze. The near-turn alignment, vertical steering and 8-unit/1-pixel orthogonal correction are recovered from the original executable. This is a source-level reconstruction of these branches, not certification of every simultaneous-axis, transition-frame or x87 detail. Regression covers a slanted corner, idle capture, dead end and physical Spud Up/Down.
